# Base Polo norte

**Nombre Código**: GPN-001
**Ubicación:** Polo Norte, Océano Ártico
**Responsable:** Capitán Nemo
**Estado:** 🟢 Operativa

## Descripción general

La Base Polo Norte es una instalación de investigación y operaciones estratégicas ubicada en el extremo norte del planeta. Construida sobre una plataforma flotante, la base está diseñada para soportar las duras condiciones del Ártico y servir como punto de control para misiones científicas y militares.

# Instalaciones

- Laboratorio de investigación climática y oceanográfica
- Hangar para vehículos de exploración submarina
- Dormitorios y áreas de recreación para el personal
- Centro de comunicaciones satelitales
- Plataforma de lanzamiento para drones y vehículos aéreos no tripulados
